# Države i gradovi

Ema Badurina

**Licenca: CC-BY 4.0** - više u LICENSE.md

**Podatci** su preuzeti sa mrežne stranice [GeoNames](https://www.geonames.org/)

**Verzija podataka:** 1.0

**Jezik:** Hrvatski

Opis atributa:
- id - id države
- country - država tj. naziv države
- country_population - broj stanovnika države
- area - površina države
- iso_code - univerzalni kod pojedine države
- continent - kontinent/naziv kontinenta
- currency - valuta/naziv valute
- currency_code - univerzalni kod za pojedinu valutu
- city - grad/naziv grada
- postal_code - poštanski broj grada
